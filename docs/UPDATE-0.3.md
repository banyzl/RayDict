## 微信聊天消息怎么查词

推荐使用已经验证的复制流程：

1. 在微信聊天消息里拖选文字，按 **⌘C**。如果没有复制成功，右键选择 **复制 / 拷贝**。
2. 在 Raycast 搜索并运行 **剪贴板查词**。
3. 确认文字，可删去整条消息里不需要的部分；按 **⌘↵** 查询。

可在 Raycast 设置中为「剪贴板查词」绑定自己的全局热键。在普通查词页面，**⌘⇧V** 也能打开此入口。

「查询选中文字」保留原有行为；在微信读取失败时，新版会尝试「兼容取词（复制选区）」：返回原应用，读取系统选区，或执行微信自己的复制菜单。成功后显示确认页，用户提交后才会向已启用的词典发起查询。

兼容方式仅接受新复制的文字，不会把旧剪贴板自动当成微信选区。程序会备份并恢复剪贴板的文字、HTML 等格式；期间若用户自行复制了新内容，则保留用户的新内容。空内容、非文字内容和超过 3000 字符的输入会被拒绝。

## 能解决到什么程度

可以通过复制后查词绕过原来的单一路径失败。**微信聊天消息的系统选区读取限制仍然存在，不能保证所有消息都能一键自动取词。** 部分消息可能只能复制整条内容，此时在确认页留下要查询的单词即可；完全不提供复制的内容，本版没有 OCR 入口。

本机检查时，微信聊天区只暴露了窗口和菜单，没有向辅助功能提供文字内容。兼容取词实际运行后，在没有新复制内容时正确返回恢复页；没有误查旧剪贴板。剪贴板确认页到真实查词结果的流程已经验证。

尚未验证用户原先指定的那条聊天消息能否自动取词成功，因此不把这个结果表述为“微信直接选词已全面修复”。如果只有微信失败，不能据此认定 Raycast 权限缺失；如果所有应用都失败，再检查系统设置 → 隐私与安全性 → 辅助功能中的 Raycast 权限。

调研依据：[Easydict 的取词说明](https://github.com/tisfeng/Easydict/wiki/%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98)及[官方项目发布说明](https://github.com/tisfeng/Easydict/releases/tag/2.10.0)也记录了部分 macOS 应用不支持辅助功能取词，需要复制取词或菜单动作取词。本次使用系统 API 独立实现，没有引入第三方取词程序。

## 新增 5 个词典

| 词典 | 提供的内容 | 是否需要密钥 |
| --- | --- | --- |
| 必应词典 | 英汉释义、音标、双语例句、英美发音 | 否 |
| 海词词典 | 英汉释义、英英解释、音标、例句 | 否 |
| 牛津高阶学习词典 | 英英释义、用法例句、英美发音 | 否 |
| 朗文当代英语词典 | 英英释义、例句、英美发音 | 否 |
| 维基词典 · 英语 | 英语释义、词性、例句、出处与许可 | 否 |

在 **词典设置窗口 → 未启用** 中勾选需要的词典即可。新版迁移只添加这些选项，保留原词典的设置、启用状态、排序、情景及当前情景，不自动让每次查询多访问五个服务。

词典目录现在共有 14 个来源，包含原有词典、翻译、AI 和本地术语库；Raycast 命令从原来的 7 个增加到 9 个，新增「兼容取词（复制选区）」与「剪贴板查词」。旧命令标识和偏好字段保持兼容。

全部新来源均已通过本机真实查询：`abstraction` 与 `run`；牛津另外验证了大写 `Run`。补测发现牛津 `run` 会跳转至 `run_1`，本版已支持最多三次同站点跳转。带密钥的 JSON API 请求规则未改动；跨站点跳转仍会停止。首字母大写的条目只有在原样查询返回 404 时才尝试小写，不覆盖已经存在的专有名词词条。

柯林斯、韦氏和词源网在本机直接访问返回验证拦截，本版没有把它们列为可用来源，也没有绕过验证。新增网页词典仅解析公开词条，不执行网页脚本；网站改版、验证和限流仍可能影响可用性。新来源的结果只用于本次展示，收藏保留查询、笔记和来源链接。

词典原站：[必应](https://cn.bing.com/dict/)、[海词](https://dict.cn/)、[牛津高阶](https://www.oxfordlearnersdictionaries.com/)、[朗文](https://www.ldoceonline.com/)、[维基词典](https://en.wiktionary.org/)。

## 以后如何更新

本机项目仍在原来的 `raydict` 文件夹内，已更新至 0.3.0。日常直接在 Raycast 使用；修改源码或取得新源码后，在项目目录执行：

```sh
npm run update:local
```

从项目包在其他 Mac 安装时，解压后在 Raycast 的 **Import Extension** 中选择 `raydict` 文件夹，再执行 `npm ci` 和 `npm run install:local`。包内独立设置程序为 Apple Silicon 版本；需要重新编译时使用 Apple Command Line Tools。

本地扩展没有 Store 自动下载更新。本次保留 Raycast 和其他 Store 扩展的更新设置，不修改 Raycast 数据库或伪造商店身份。
