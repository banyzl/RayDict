## 本机界面验证

已用 `npm run dev` 加载 RayDict，并在 Raycast 中验证：

- 能找到全部 5 个命令。
- `abstraction` 自动并行查询英文词典和本地术语。
- 左侧切换词典，右侧显示完整内容、音标、例句与来源。
- `⌘S` 保存快照成功。
- `⌘M` 打开 Provider 管理，显示按 Profile 排列的词典。
- 系统选词命令可进入查询界面；选区为空时回退到手动输入，来源应用显示 TextEdit。有效选区、全局热键及不同应用兼容性仍需继续实机验证。

## 验证边界

DeepL 与 Raycast AI 尚未使用用户密钥/账户进行真实调用。Anki 集成以本机模拟服务验证协议，没有向用户真实牌组添加卡片。词典音频和系统朗读接口已实现，但尚未完成不同音频格式、声音/口音和长文本的完整实机覆盖。没有验证 WebDAV 或其他远程同步，因为第一版未实现同步。

受限环境不允许监听本机端口时，集成测试会返回 EPERM；在允许本机测试服务的执行环境中，14 项测试全部通过。并未为了让测试通过跳过集成测试。
