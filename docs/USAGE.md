# RayDict 使用指南

适用于 0.4.0。安装步骤见[项目首页](../README.md)。

安装完成后，在 Raycast 搜索 **RayDict**：

| 命令 | 用途 |
| --- | --- |
| 查词 / Search | 左侧词典结果，右侧完整词条，多词典并行查询 |
| 查询选中文字 | 读取当前应用选区；微信失败时自动尝试兼容取词 |
| 兼容取词（复制选区） | 返回原应用读取选区或调用复制菜单，先确认文字再查询 |
| 剪贴板查词 | 微信先复制文字，再预览、编辑并提交查询 |
| 词典设置窗口 | 打开独立的 macOS 图形设置窗口 |
| 管理词典与情景模式 | 与旧入口、热键兼容，同样打开独立设置窗口 |
| 生词本 | 上下文、笔记、结果快照、导出和 Anki |
| 查词历史 | 重新查询与管理最近记录 |
| API 密钥设置 | 打开 Raycast 的密码偏好设置 |

可以先查询 `abstraction`、`implicitly` 或「抽象」。在查询界面按 `⌘M` 打开独立设置，`⌘P` 切换情景，`⌘S` 收藏，`⌘⇧E` 补充上下文与来源。手动词典需要选中后按回车，更多操作位于 `⌘K`。

右侧结果使用完整可用高度。情景显示在右上角，来源和阅读上下文放在正文末尾，随词条一起滚动，不再占用独立的下方区域。

## 词条选择、原形与拼写候选

维基百科遇到 `run` 这样的消歧页时，会显示「选择词条」，不再把“可能指……”的简介当作完整内容。选中维基百科后按回车，输入文字筛选候选，再按回车查看具体条目。完全匹配的百科条目仍直接展示；未命中时显示官网提供的搜索与拼写候选，不再静默选取第一条搜索结果。

部分词典也支持：

- **有道**：释义明确说明原形时，例如 `ran → run`、`children → child`。
- **维基词典 · 英语**：使用原站明确标注的词形关系，例如 `went → go / wend`。
- **牛津、海词**：未找到词条时显示原站拼写候选，例如 `receve → receive`。

已有释义时按 **⌘J** 打开「词形与可选词条」；只有候选时直接按回车。选择只更新当前词典，其他词典保留当前结果。操作菜单中的 **返回原查询** 可立即恢复原结果。查询框仍保留最初输入，右栏会标明当前选中的词条。

没有可靠选项的来源保持原行为，不推测通用词根，也不自动替用户纠错。百科候选来自消歧页实际链接或官方搜索，最多显示 100 个；未链接的名称不虚构跳转。官网故障时会提示重试，并可使用「在维基百科原站查看」。

详见 [0.4 词条选择与验证说明](UPDATE-0.4.md)。

## 微信聊天消息取词

微信聊天区域不一定向系统提供所选文字，只有选区高亮不代表 Raycast 能读取。现在「查询选中文字」会在微信直接取词失败时尝试兼容方式：返回微信读取选区，或调用微信菜单中的「拷贝 / 复制」。成功后先显示文字供确认，再开始查询。

最可靠的复制路径：

1. 在微信聊天消息里选中文字，按 `⌘C`；若无效，右键选择「复制」。
2. 在 Raycast 打开 **剪贴板查词**。
3. 确认或删改文字，按 `⌘↵` 查询。微信若复制了整条消息，可在此只留下需要的单词。

也可以给 **兼容取词（复制选区）** 或 **剪贴板查词** 绑定自己的全局热键。查词页面按 `⌘⇧V` 同样可以打开剪贴板确认页。

兼容方式不会把旧剪贴板静默当作选中文字；仅在复制内容确实变化后读取，并恢复原剪贴板中的文字、HTML 等格式。复制期间若用户自行复制了其他内容，则保留用户的新内容。取词失败会显示可操作的恢复页，不再只有一条错误提示。

兼容取词仍受微信选区、复制菜单和系统辅助功能权限限制。验证机已验证微信未产生新复制内容时正确停止，以及剪贴板确认后正常查词；**尚未验证所有微信聊天消息的自动取词成功，不能保证所有微信消息都能单步取词**。不支持复制的内容目前没有截图 OCR 入口。

## 独立图形设置

左侧选择情景，中间选择词典，右侧修改该词典的设置：

- 直接勾选启用或停用，不必打开操作菜单。
- 通过右侧「上移 / 下移」调整查询顺序；列表也接入系统排序交互。
- 「添加词典」打开内置目录，一键添加到当前情景。
- 「配置词典」修改名称、查询方式、内容语言、适用文字和超时。
- 自定义 API 使用表单，音标、例句、请求头和认证放在高级选项中。
- 需要时可通过查词操作菜单进入「Raycast 内简易管理」。
- 新建、编辑、删除情景；新情景沿用当前词典组合。
- 导入、导出配置备份。启停与顺序自动保存，编辑表单使用「保存修改」。

![独立设置窗口](settings-window.png)

设置通过共享文件同步到查词界面，正在运行的命令约 1 秒内刷新。两边同时编辑时会拒绝旧版本覆盖，并提示刷新。真实密钥仍放在 Raycast 的密码设置中，可以从独立窗口直接打开；配置使用密钥槽位引用。

新增的五个词典已加入词典目录。已有用户的启用状态和排序保持原样：在 **词典设置窗口 → 未启用** 中勾选即可使用。

有道、剑桥、汉典、必应、海词、牛津与朗文只读取公开页面，提取后在原生界面显示；不执行网页脚本，不使用浏览器 Cookie，不绕过验证。网页改版、验证或限流可能影响查询。当前有道覆盖基础词义与双语例句，未完整复刻网页中的所有扩展板块。

有道和剑桥的网页内容只在本次查询中展示，不写入结果缓存或生词快照；收藏保留查询、上下文、笔记与来源链接。汉典、维基百科和其他可保存的结果保留其出处与许可信息。新增五个来源均只在本次查询中展示结果，收藏保留查询、笔记和来源链接。柯林斯、韦氏及词源网在验证环境返回验证拦截，本版没有把它们作为可用选项加入。

## 添加自己的 API

「词典设置窗口 → 添加词典 → 添加自定义 API」。例如响应：

```json
{"data":{"entries":[{"word":"example","meaning":"示例","ipa":"/…/","examples":["An example sentence."]}]}}
```

填写词条数组路径 `data.entries`、释义路径 `meaning`、单词路径 `word`、音标路径 `ipa`、例句路径 `examples[]` 即可。支持 GET / POST JSON，URL 和请求体中可使用 `{word}`、`{source}`、`{target}`、`{context}`。

在 Raycast 的密码设置填写 API 密钥 1–3，选择相应槽位，并在请求头使用 `{"Authorization":"Bearer {token}"}`。不要把真实密钥写入可导出的配置正文。纯 HTML URL 需要专用 Provider，复杂接入可编写 TypeScript 模块。

详见 [Provider 说明](PROVIDERS.md) 与 [JSON 配置示例](../examples/custom-json-provider.json)。




系统选词取决于宿主应用及 Raycast 辅助功能权限；它不保证取得周围整句或原文链接。可在查询中手动补充这些信息。普通在线词典仍需网络，独立于浏览器不代表完全离线。

Anki 需要运行桌面版并启用 [AnkiConnect](https://git.sr.ht/~foosoft/anki-connect)。在 Raycast 扩展设置中填写已有牌组、笔记类型、正面/背面字段及可选 API Key。当前使用仍受支持的 version 6 兼容协议，先检查模型与牌组再制卡，默认拒绝重复。尚未用用户真实牌组验证，也没有自动媒体导入、Cloze 或批量同步。

词典配置位于扩展 supportPath 的 `settings-v1.json`，由两边共享，带修订号、写锁和原子保存。旧 LocalStorage 配置首次加载时迁移，旧值保留。生词本和历史分别位于 `notebook-v1/`、`history-v1/`，这些 JSON 文件未额外加密。历史默认保留最近 300 条成功查询，可关闭或清空。

远程词典会收到查询文字；支持上下文的翻译、AI 或自定义 API 也会收到用户提供的上下文。翻译和 AI 默认手动触发。当前未实现远程同步、全文翻译或鼠标旁浮窗。
