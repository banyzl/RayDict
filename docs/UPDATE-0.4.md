# RayDict 0.4.0 · 词条选择、原形跳转与拼写候选

> 历史记录：以下为对应版本在验证机上的调查与验证；当前源码安装步骤见[项目首页](../README.md)。


日期：2026-10-28。本机已安装新版，保留原有 9 个命令、词典设置和本地使用方式。

## 可行性结论与已实现范围

| 功能 | 采用的可靠依据 | 当前支持 |
| --- | --- | --- |
| 维基百科消歧 | 官方 `disambiguation` 标记、页面正文中的真实词条链接 | 支持，最多 100 个候选，可筛选 |
| 百科未命中与拼写建议 | MediaWiki 官方搜索结果与 `suggestion` 字段 | 支持，需用户选择，不自动替换 |
| 有道原形跳转 | 释义明确写出的“某词的过去式 / 复数”等关系 | 支持这些明确关系 |
| 维基词典原形跳转 | 英语词条中的 `form-of-definition-link` | 支持，保留多个可能原形 |
| 牛津拼写候选 | 官网未命中页面的 `dym-link` 建议 | 支持，包括 404 页面中的建议 |
| 海词拼写候选 | 官网“您要查找的是不是”列表 | 支持 |
| 其他来源 | 尚未验证稳定的词形或建议结构 | 保持原有查询行为 |

不通过删去 `s`、`ed` 等后缀猜原形，不把网络搜索中碰到的相近词冒充词典建议，也没有加入额外的拼写服务或 AI 自动纠错。

官方依据：[Disambiguator API](https://www.mediawiki.org/wiki/Extension:Disambiguator#With_API)、[页面解析接口](https://www.mediawiki.org/wiki/API:Parsing_wikitext)、[搜索与建议字段](https://www.mediawiki.org/wiki/API:Search)。其中消歧标记的值可能是空字符串，需检查字段是否存在，不能按布尔值判断。

## 怎样使用

### 维基百科对应多个条目

以 `run` 为例：选中左侧「维基百科」，右侧显示候选概览，按 **回车** 打开完整候选列表。可以输入文字筛选，例如 `Running` 或电影标题；选中后按回车，只加载当前百科条目的正文。

完全匹配的普通百科条目仍然直接显示。没有完全匹配时，会列出官方搜索候选，不再自动加载第一条结果。只有候选时使用独立状态，不把它标为已取得释义，也不会单独作为有效释义收藏。

消歧页只收录带真实正文词条链接的候选；导航、帮助页、站外链接、红链以及正文后半句中提到的演员等附带链接会被排除。部分没有独立词条链接的名称不会生成虚构选项。

### 查看单词原形

- 在有道查询 `ran`，右侧会显示 `run` 及其关系说明。
- 按 **⌘J** 打开「词形与可选词条」，选中 `run` 后按回车。
- 右栏展示 `run`，并标明当前词条；查询框仍保留 `ran`，其他词典继续展示原来的 `ran` 结果。
- 通过操作菜单的 **返回原查询** 恢复刚才的 `ran` 结果，不重新请求所有词典。

例如 `went` 在维基词典可能对应 `go` 与 `wend`，会保留来源给出的多个选项，由用户决定。

### 输入错误时的候选

在牛津或海词查询 `receve`，会显示原站提供的 `receive` 等候选。按回车打开候选列表并选择；仅更新当前词典，不改动主查询或其他词典。没有来源提供的候选时仍显示无结果，不强行替换输入。

## 保留的体验和数据

- 保留原有双栏、多词典并行查询、情景、设置、历史、生词本与 Anki 实现。
- 有正常释义时，回车复制结果的行为保持原样；附加候选通过 **⌘J** 或操作菜单进入。
- 只有候选时，主操作才变为「选择词条」。
- 选择或返回只影响当前词典；没有自动把候选词发送给所有服务。
- 切换后刷新仍查询当前所选条目；返回原查询会恢复之前的结果。
- 针对每个词典单独取消过期请求，较早的响应不能覆盖后选的词条。
- 原查询和选中词条使用不同缓存键，避免重新输入 `run` 却拿到此前选择的其他文章。
- 没有新增配置字段或修改词典启用、排序与热键标识。仍使用一次性本地构建，不开启 Development 监听。

## 验证记录与限制

- 44 项测试通过，覆盖消歧空字符串标记、真实链接筛选、搜索建议、语言保持、原形与拼写来源、单词典切换、返回、并发取消和缓存隔离。
- TypeScript、ESLint、格式检查、9 个入口优化构建，以及原生设置和剪贴板保护自检通过。
- 本次从真实英文 `Run` 消歧页面解析出 72 个有效候选，首项为 `Running`。
- 有道 `ran → run`、维基词典 `went → go / wend`、牛津和海词 `receve` 候选均通过真实查询验证；牛津选择 `receive` 后成功取得正文。
- 在 Raycast 实际完成 **查询 ran → ⌘J → 选择 run → 查看正文 → 返回 ran**，其他词典保留原结果。

**百科在线验证的限制：** 本次取得真实页面和消歧数据后，Wikimedia 接口在多次后续请求中间歇返回 HTTP 503，影响了百科候选到正文的完整在线复查。已通过真实响应结构测试及共享选择界面的实测，但不把当前网络下的百科完整线上流程表述为已全部验证。服务故障时会提示稍后重试，并提供「在维基百科原站查看」，不会伪造候选、绕过验证或静默改查其他服务。

英文分支取得了真实消歧数据；中英文语言保持有测试覆盖，中文百科本次在线请求未取得稳定响应。网站改版和服务故障仍可能影响各来源，不代表所有词形或拼写错误都会有候选。

## 更新与项目位置

本机原有项目已经更新到 0.4.0。今后修改或取得新版源码后，在项目目录运行：

```sh
npm run update:local
```

日常直接使用 Raycast。项目包保留源码、测试、文档和 Apple Silicon 原生设置程序；在另一台 Mac 安装时，解压后导入 `raydict` 文件夹，执行 `npm ci` 和 `npm run install:local`。
